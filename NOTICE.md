# Attribution

This project is an experimental extension of the public FraudGT repository:

- Upstream project: `junhongmit/FraudGT`
- Upstream URL: https://github.com/junhongmit/FraudGT
- Base commit used by the experiments:
  `f88db9dc003a6f521a90631c4741541686043119`
- Paper: *FraudGT: A Simple, Effective, and Efficient Graph Transformer for
  Financial Fraud Detection* (ICAIF 2024)

The upstream repository did not include a single root-level license file in
the source snapshot used here.  Several vendored GraphGym subdirectories carry
their own license notices; those notices are preserved.  Confirm the upstream
usage terms before public redistribution.

Original additions in this extension are documented in the root README and
include the multi-view gated downstream head, weighted focal loss, threshold
selection utilities, T4 experiment configs, tests, and experiment notebooks.
